# When Memory Undermines Rules in Self-Evolving Agents

Anonymous code release for the paper of the same name, under double-blind
review.

Self-evolving agents rewrite their procedural memory between tasks, and the
standing rules a user gives them often live in that memory. This repository
contains the harness and analysis code used to test whether such rules keep
their force as memory evolves. The rules stay visible and verbatim
throughout.

## Contents

| Path | What it is |
| --- | --- |
| `self_evolving_agent/safety_retention/` | The harness: virtual desktop and policy oracle (`environment.py`, `desktop.py`), memory streams and episodes (`experiment.py`), memory controls such as length-matched, token-matched and rule-deleted memories (`memory_ablation.py`), the approval check (`approval_gate.py`), model backends (`backends.py`), and the MailShare browser environment (`mailshare.py`). |
| `self_evolving_agent/` (other modules) | Shared model clients (`llm.py`, `bedrock_client.py`) and utilities the harness imports. |
| `configs/safety_retention_*.json` | Model configurations (DeepSeek API, Amazon Bedrock models, locally served open models). They hold no credentials. |
| `scripts/run_safety_retention.py` | Runs self-evolution streams: training episodes, memory updates and checkpoint audits. |
| `scripts/run_memory_replay.py` | Replays held-out probes under saved memories and controls (no-rule, rules-only, length-matched, rules pinned, self-check, enforcement, dense checkpoints, surgery). |
| `scripts/tally_*.py`, `stream_bootstrap.py`, `cluster_bootstrap.py` | Tables and stream-level bootstrap intervals. |
| `scripts/make_evolution_figure.py`, `make_paper_figures.py` | Figures. |
| `scripts/steer_server.py`, `steer_vectors.py`, `rule_axis.py`, `analyze_rule_axis.py` | Activation steering and the rule-presence direction (open models, Hugging Face Transformers). |
| `scripts/mailshare_label_audit.py`, `label_agreement.py`, `make_exploit_surgery.py` | Second-model label audits and targeted memory surgery. |
| `tests/test_safety_retention.py`, `tests/test_mailshare.py` | Unit tests and scripted browser episodes, with no model calls. |
| `reports/` | Result tables generated by the tally scripts. |

Run outputs (model call ledgers, episodes, memories) are not included.

## Setup

Python 3.11+.

```bash
pip install numpy matplotlib pytest playwright tokenizers
python -m playwright install chromium-headless-shell   # MailShare only
pip install torch transformers                         # steering / rule direction only
```

Credentials come only from environment variables:

| Variable | Used for |
| --- | --- |
| `DEEPSEEK_API_KEY` | DeepSeek API configurations |
| `AWS_BEARER_TOKEN_BEDROCK` | Amazon Bedrock configurations |
| `LOCAL_VLLM_KEY` | Locally served OpenAI-compatible models (vLLM or `steer_server.py`) |

Optional paths:

| Variable | Used for |
| --- | --- |
| `LOCAL_VLLM_KEY_FILE` | Key file read by `steer_server.py` |
| `DS_TOKENIZER` | `tokenizer.json` used for token-matched padding |

The locally served configurations point at a `base_url` that you set for
your own server.

## Quick start

```bash
# tests (no model calls)
python -m pytest -q tests/test_safety_retention.py tests/test_mailshare.py

# model-free smoke run of the harness
python scripts/run_safety_retention.py --backend scripted --output runs/smoke

# one self-evolution stream with a real model (writes runs/<name>/)
python scripts/run_safety_retention.py --backend llm --manifest MANIFEST.json \
    --output runs/stream --model-config configs/safety_retention_deepseek_flash_v3.json \
    --max-calls 6000 --max-cost-usd 3

# replay held-out probes under the stream's checkpoint memories and controls
python scripts/run_memory_replay.py --run runs/stream --output runs/stream_replay \
    --templates heldout_c_settings_purge --variants none length_matched --arms pinned \
    --trials 2 --model-config configs/safety_retention_deepseek_flash_v3.json \
    --max-calls 20000 --max-cost-usd 2
```

Manifests for the desktop study are produced by the fixture modules in
`self_evolving_agent/safety_retention/` (`drift_fixtures.py`,
`stress_fixtures.py`). MailShare manifests come from
`self_evolving_agent.safety_retention.mailshare.make_mail_manifest`. The tally
and figure scripts read run directories under `runs/`; their paths follow the
naming used in the paper's experiments.

## Notes

- Every policy label comes from a programmatic oracle (`violations` in
  `environment.py`; `mail_violations` in `mailshare.py`). No human
  annotation is involved.
- All synthetic data (files, emails, names, domains such as
  `northwind.example`) are fictional sandbox content.
